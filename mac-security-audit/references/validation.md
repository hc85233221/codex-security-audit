## v3.1 新增驗證

- AI 設定與近期檔案：以合成資料測試敏感內容不輸出、聊天與憑證名稱略過、日期及來源未知、符號連結／祖先目錄置換、硬連結、FIFO、檔案與總量上限、Windows 中繼資料模式及私人輸出。
- 更新支援：以模擬 GitHub 回覆與 ZIP 測試固定來源、版本與 commit 解析、完整校驗碼、路徑跳脫、重複與特殊項目、下載及解壓上限、本機修改辨識、候選暫存與未覆蓋舊版。
- 報告整合：測試只補 AI 模組、命名範圍隔離、不可回報 pass、觀察日期保存、清單替換、不可信檔名跳脫與報告模板校驗碼。桌機與手機介面使用假資料驗證，不把示範資料當作實機結果。
- Mac 本機補查僅在使用者授權的下載與輸出位置進行。完整範圍、略過及數量限制保留在個人報告，不夾帶到分享包。
- Windows 原生健檢與更新尚未實機驗證。無安全目錄讀取能力時，新增 AI 檔案模組只看頂層中繼資料，更新比對保留未確認，不假稱完成。

- 報告整合：24 項測試通過，包含原有補查、Codex 來源、exposure 命名邊界、目標報告與全機報告分離，以及失敗狀態與日期保留。

- 新介面：桌機與手機合成測試涵蓋被動三模式、URL 遮蔽、需求複製及未執行狀態、行內解釋、鍵盤頁籤、篩選、完整列印、目標模式、XSS 與無外部請求；全部通過。螢幕及列印 computed-style 對比檢查通過，獨立視覺複核 disposition 為 ship。這些是介面驗證，不是 Windows 原生收集器實機驗證。

## 既有驗證基礎

- Mac 實機：六個模組完整串接執行，包含系統、瀏覽器、skills、Wi-Fi、藍牙、應用程式、限定範圍腳本及背景程序；HTML／JSON 成功生成，欄位依作業系統回覆呈現，讀取不完整保持 partial／unknown。
- Windows 收集與原生 I/O：22 項模擬測試通過，包括 Defender 被動模式、BitLocker 保護暫停、權限不足、無線識別資訊過濾、藍牙不發起探索、服務與排程範圍，以及 protected DACL／Job Object 的 ABI 與參數。
- Mac 無線、程式、使用統計匯入、腳本及背景收集：21 項測試通過，包含不以快照推論使用率、非法統計拒絕、特殊檔案與重導向跳過、深度與數量上限。
- 獨立安全複核：13 項測試通過，包含 SQLite 惡意 view、Cookie 值不輸出、WAL 不建立 SHM、嵌入 JSON 跳脫、symlink／reparse、防止 Unix mode 被誤當 Windows ACL，以及只終止自建逾時程序群組。
- 舊版回歸：12 項技能靜態掃描測試、瀏覽器資料不變與覆蓋隔離情境通過。空 journal 可以在穩定性檢查下唯讀查詢；非空 journal／WAL 略過。
- 介面：Chrome / Playwright 檢查 390、768、1024、1512 px 版面、鍵盤頁籤、搜尋篩選、假資料標籤、無外部請求、惡意字串不執行；列印含六個盤點頁籤、全部檢查與展開證據。v2.1 名詞說明改為 tooltip，不再使用獨立章節與名詞對話框。
- Skill 結構驗證器的規則通過；環境缺少 PyYAML，因此用既有 Ruby YAML 解析器銜接驗證器，未額外安裝套件。

## 尚未驗證與已知範圍

- 沒有可用 Windows 實機。因此 Windows PowerShell 在實際作業系統的解析／回覆、Wi-Fi 驅動相容性、真實 DACL 效果與 Job 行為尚待 Windows 10／11 使用者驗證。模擬測試不能取代這部分；不得宣稱 Windows 實機已通過。
- Windows 需 Python 3.9+、內建 PowerShell 5.1、支援 ACL 的本機固定磁碟。企業政策或有限權限可能使項目不可讀；先說明並詢問使用者，不能自動提權或變更執行原則。
- Windows 備份可靠性、Store／可攜式程式、BLE、程式簽章與來源 ACL 並未完整覆蓋；更新只取本機紀錄。Mac 也不是完整系統日誌或全磁碟掃描。
- 瀏覽器檔案只查支援的預設位置；搬移／重新導向位置、Safari 或受限資料庫可能未涵蓋。
- 使用統計由使用者提供，顯示來源與期間，但未核驗原始事件。缺少統計時不產生真實常用排行。
- Spotlight 最近開啟可能未記錄、延遲或受權限限制，不保證涵蓋每次執行，也不能用來判定應刪除程式。程式名稱補列不代表完成版本、簽章或來源驗證。
- 備份補查不使用可能隱含掛載目的地的 latestbackup；最近成功日期與可還原性需由適當介面或另行授權的還原測試確認。
- 報告無網路載入與上傳功能；AI 對話本身的資料處理仍取決於使用環境。分享時不得包含私人報告。

自動化邊界測試使用合成資料；正式分享包不包含私人實機報告。
